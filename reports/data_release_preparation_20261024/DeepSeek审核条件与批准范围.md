# DeepSeek 审核条件与工程批准范围

本轮由用户授权 AI 代替逐题人工审阅，总 API 硬上限 $5。记录保留审核方法、原始回应、请求 ID、版本及费用；不写成逐题人工签字或数学金标。

- 数学：检查题意、条件、定义域、分支、符号、指数系数、等号条件、端点、单位及推导。匹配最终答案不足以证明过程正确。
- 代码：检查完整题面与完整参考代码、函数或 stdin/stdout 契约、一般输入格式、约束、复杂度和边界。前三个用例仅是明确标注的节选；容器通过及常量 mutant 被杀死不足以证明覆盖充分。
- 数据：检查缺图、歧义、题面夹带答案、角色/翻译指令、多问单答、题答冲突。开发集保持原分割，审核结果不变成训练种子。
- 配对：审核同题原生和精炼两条完整轨迹；检查未纠正的错误等式、非法分支和残缺公式。两组同时改变教师、提示词和长度，不能仅归因于去除过度思考。
- 视觉：实际发送原图；逐个条件区分图像独占、文字显式/蕴含和不确定；只接受像素中能确认的点名及无歧义圆身份。内部 radius ID、未印出的点名和圆心名均不能当成可见证据。视角/比例不能代替刻度或几何符号证据。
- 结论：pass / isolate / uncertain，附可核查条件；格式不完整、输出截断、pass 与问题标记矛盾时转待定。API 审核意见也可能错误，独立复测与审核冲突时保留待定和两方证据，不改写原始结论。
- 准入：只把通过相应审核和确定性检查的训练子集导出为工程批准版本，逐项声明使用范围；原始全集和待定项继续保留。项目三批准只限感知监督原型，不伪造 reasoning，也不把部分标签当作完整类别的 RL 奖励金标。
- 费用：已完成请求按峰值价用量核算，在途和未知失败保留最坏费用预留，二者合计不超过 $5。项目一每题只生成一次；项目二只有 URLError 可在保留原费用预留后额外尝试一次，不因语义审核不通过而重抽一个更好看的判决。

实际发送的英文完整 system 契约见 ../../src/synthesis/data_review_contract.py；视觉专用契约见 ../../scripts/review_geometry_grounding.py。冻结政策及源文件哈希在各审核目录的 policy/manifest 中。
