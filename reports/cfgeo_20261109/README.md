# CF-Geo 评测集（2026-11-09）

E2（读图）的评测集：把图上的长度数字乘 2（k=2），标准答案按量纲变化；同时把同样的数字擦掉后原样重画（k=1），作为编辑伪影的对照。
规则见 [S3 设计](../../docs/plan/S3设计_20261109.md) 第 3 节和第 11 节（修订 1）、决策 D45；构造脚本 `scripts/data/build_cfgeo.py`，
重建代码 `src/evaluation/cfgeo.py`。

## 评测集的组成

- 候选 224 题（[评测集定义](../eval_sets_20261109/README.md)），通过编辑核验 158 题（71%）。
- 答案精确的 106 题，标准答案为 k^d 乘原答案（sympy 计算，并用判分器确认等价）；要求取整的 52 题，按“正确取整的集合”判分
  （例如原答案 56.6、长度乘 2 时，113.1、113.2、113.3 都算对；原图和 k=1 时集合只有原答案本身）。
- 量纲：求长度 123 题（k=2 时答案乘 2），求面积 35 题（乘 4）。
- 排除的 66 题：OCR 读到的含数字文字不是纯数字标注 21，读到标注里没有的数字 13，数字与同色笔画相连无法分开 10，
  新数字会盖住其他墨迹或贴住其他标注 10，OCR 没找全标注 4，重画后核验未通过 5，其他 3（标注外的角度 1，新数字会超出图像 2）。

## 文件格式

每题记录：题目编号（`validation:<行>` 或 `test:<行>`，即包装数据 parquet 的行号）、原图像素哈希、InterGPS 编号、原答案、量纲次数、
取整位数，以及 `k1`、`k2` 两种编辑。每种编辑有：

- `edits`：若干矩形补丁。补丁是 RGBA PNG，alpha 为 255 的像素是我们填的背景色或画的数字，其余像素 alpha 为 0、颜色存为 0。
  不含任何原图像素，仓库里也没有原图。
- `pixel`：编辑后整图的像素 SHA256（与 `src/data/project3_audit.image_hash` 相同的算法）。
- `answer` 或 `answer_set`：这张图的判分依据。
- `labels`：每个被改的标注：原文字、新文字、字号、水平压缩比、描边宽度、原 OCR 框、新数字框、背景色和文字颜色。

VM 上的重建：下载固定版本的包装数据，核对 SHA256，取出原图，核对原图像素哈希，贴上补丁，再核对编辑后的像素哈希；任何一张不一致就失败。
贴补丁不经过字体渲染和 PNG 编码，所以不同机器上得到的像素相同。

## 开发过程（只用 train）

编辑规则先在 train 上开发，定稿并推送到 GitHub 之后，才第一次对 validation 与 test 运行。每一版在 train 上的通过情况：

| 版本 | 做法 | train 结果 |
|---|---|---|
| 设计原稿 | 整框填背景色；框外一圈颜色不均匀就排除；不允许带单位 | 试 431 题，留 60 题（14%）；主要排除原因：旁边有线条 166，带单位 153 |
| 中间版本 | 按颜色区分数字和线条；再改为按连通块；擦掉淡边；字形按原宽度压缩 | 依次为 60/263、1/520、60/186、60/134、60/113 |
| v2（修订 1，定稿） | 连通块擦除，伸进框内的同色笔画排除；允许 cm、in. 等单位 | 试 88 题，留 60 题（68%） |
| v3（抽查后的全局修正） | k=1 原样重画印刷字符串；描边匹配原数字的粗细 | 开发集试 58 题，留 40 题 |

v2 在 validation 与 test 上通过 159 题。第一轮抽查发现两个问题（见 [spot_check.md](spot_check.md)），按抽查规则改成 v3 后全部重建，
通过 158 题；第二轮抽查 30 题都可用。
