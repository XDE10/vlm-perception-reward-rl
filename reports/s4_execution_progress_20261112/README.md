## 1. 外部审查决议与去偏置修正 (Route B)

针对前期代码审查提出的偏置隐患，经项目全量代码审计后确认两项关键问题，并正式采纳**路线 B（Decision D66，Pre-registration Revision 4）**：

1. **零命中批次梯度劫持修复**：
   - *问题根因*：在 `scale_rewards="batch"` 归一化下，当某个 batch 内所有采样均为零命中时，组内减均值除方差的操作会强行放大微小浮点扰动，且感知权重 $\lambda$ 被方差抵消，导致感知奖励反向支配答案梯度。
   - *修正方案*：在 `configs/experiments/rl_v3_p1_20261110.json` 中配置 `train.scale_rewards: "none"`，严格回归标准 Dr.GRPO 无偏设计，杜绝批次奖励归一化带来的信号扭曲。
2. **标签损坏惩罚安全岛漏洞修复**：
   - *问题根因*：当模型生成损坏的 `<perception>` 标签时，旧逻辑返回 0 分，而在真实预测但未命中任何有效事实时的惩罚为 `-0.05`，导致产生“破坏标签即可逃避惩罚”的逆向套利空间。
   - *修正方案*：在 `src/rewards/perception_v5.py` 中将标签损坏惩罚设为 `-1.0`（加权后为 `-0.10`），严格低于最差有效解析的惩罚（`-0.05`），封闭安全岛漏洞。
3. **虚假指控澄清**：
   - 经代码审查确认，原审查中关于“Google Drive `CLAIM.json` 锁并发失效”与“`rollouts.jsonl` 重复回放导致方差失真”的指控不成立，调度器已由 `s4_state.py` 严格实现 CAS 原子锁防护与去重校验。
