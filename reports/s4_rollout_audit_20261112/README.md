空块按日志 `v5.status == "empty"` 计数。合规全 UNKNOWN 指格式分为 1、至少一条去重断言、所有断言都判为 UNKNOWN。完整任务比较首尾各 38 步，短日志比较首尾各 10 步。安慰剂组的判定依据为错配图的训练元数据。

- 旧主组的合规全 UNKNOWN 从 3.91% 升到 35.53%，只写一条 UNKNOWN 从 0.82% 升到 9.54%。末段 864 条全 UNKNOWN 中有 862 条的加权格式分与感知分之和为正。
- D66 主组 seed2 的前 38 步中，87 条合规全 UNKNOWN 有 83 条取得正的非答案奖励。对答案均错、同题同训练步、格式均合规的成对输出，全 UNKNOWN 在与含 FALSE 的输出比较时获得更高总分 275/280 次。这些是训练组内的描述性计数。
- 可见的空块极少。UNKNOWN 有获得格式分并少受感知惩罚的激励，旧主组后期明显集中到这种模式。UNKNOWN 也包括认证范围之外的真实事实，这些计数无法判断每条断言的真伪或模型意图。D66 完整主组的后段趋势待补跑完成后核对。
