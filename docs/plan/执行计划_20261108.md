## 2. 实验设计

### 2.1 统一协议（所有组完全相同，V0 评测也一样）

- 输出格式：`<perception>事实1; 事实2; …</perception><think>推理</think><answer>最终答案</answer>`。
  恢复推理段（v2 协议禁止推理是审计问题之一）。
- 输入：题面加原图，沿用现有输入白名单；答案自由作答，不给选项。
- 起点：全部从 V0（`Qwen/Qwen2.5-VL-3B-Instruct`，revision `66285546…`）出发。
  不使用"只监督感知"的 SFT，以避免审计中发现的格式断层和起点混杂。
- 训练数据：已批准的 609 道训练题（458 幅图），不扩充、不改动。
- 可训练参数：只在语言模块挂 LoRA（r=16，α=32，按精确模块名选择）。
  ViT 和 merger 冻结，并在运行时断言。

### 2.2 实验组

| 组 | 训练奖励 | 训练时有图 | 种子 | 作用 |
|---|---|---|---|---|
| V0 | 不训练 | — | — | 基线 |
| RL-ans | 答案 + 格式 | 是 | 3 | 主对照。格式奖励要求 perception 非空且可解析，所以"有没有视觉草稿"在各组相同 |
| RL-v4 | 答案 + 格式 + 现有稀疏 F1（λ=0.2） | 是 | 2 | 消融：原设计，检验"罗列事实"导致的膨胀 |
| RL-v5 | 答案 + 格式 + 可证伪感知奖励 v5（λ=0.1） | 是 | 3 | 主方法 |
| RL-v5-placebo | 同 v5，但事实与坐标取自另一张图（固定随机配对，保证不同图） | 是 | 2 | 对照：排除"任何结构化奖励都有效"（Qwen 系模型在随机奖励下也会涨分） |
| RL-blind | 答案 + 格式 | 否 | 2 | 对照：排除"只是语言能力变强" |

合计 12 个训练任务。时间允许时可选加一组：RL-v5 改用组内标准化（1–2 个种子），
用来量化"组内标准化抹掉 λ"的实际影响。

各组训练预算相同：

- 3 个 epoch；每步 8 题 × 8 条采样，共 228 步。
- 学习率 1e-5；KL β=0.01；`loss_type=dapo`；`scale_rewards=batch`；clip 0.2/0.28；温度 1.0。
- 单条生成最多 1024 token，V0 诊断后按长度分布确认。
- 评测一律用最后一个 checkpoint，不按 test 挑 checkpoint。

### 2.3 奖励定义

`R = R_answer + 0.05·R_format + λ·R_perception`

- **R_answer**：用 math_verify 判定 `<answer>` 内的内容。改成常驻进程池，保留隔离与超时。
- **R_format**：perception、think、answer 各恰好一段且顺序正确；perception 至少有 1 条可解析事实，至多 24 条。
- **v4**：现有 `scoped_score`，冻结不改，只在 RL-v4 组使用。
- **v5**：对每条断言做三类判定。
  - TRUE：属于认证正事实。
  - FALSE：与认证常量冲突，或被几何证伪，或引用了图中不存在的点，或该条无法解析。
  - UNKNOWN：其余情况。

  计分为 `R_v5 = clip((TP − FALSE − 0.1·UNKNOWN) / |G+|, −1, 1)`；断言超过 24 条直接给 −1。
- **几何证伪**：只用 InterGPS 人工标注的点坐标和线、圆实例，只做与平移无关的相对检验
  （点到直线距离、两线夹角、点到圆心距离）。几何只用来否定，不用来认证 TRUE。
  阈值只在 train 正例上选，要求 2799 条认证正例零误杀，并在 val 上报告误杀率。
- **λ 的取法**：v4 用 0.2（原设计），v5 用 0.1。两者的"λ × 奖励取值范围"相同
  （v4 取值 [0,1]，v5 取值 [−1,1]），避免 v5 组单纯因为感知权重更大而占优势。

### 2.4 评测集与指标

- **G3K val（82 题，带认证事实）**
  - 感知：认证召回、v5 验证精度（TRUE/(TRUE+FALSE)）、FALSE 率、断言条数、UNKNOWN 占比。
  - 答案准确率。
- **G3K test（601 题）**
  - 原图、无图、换图三种条件下的答案准确率。
  - 预注册的"视觉必需子集"：题面不含数字，且 InterGPS 图示逻辑式里至少有一个数值。规则只看题目，不看模型输出。
  - 用 InterGPS 标注计算的 FALSE 率。它与训练奖励同源，报告时会明确标注这一点。
- **CF-Geo（新建，从 test 的视觉必需子集构造）**
  - 把图上所有长度数字乘以 k=2，标准答案按量纲变化：求长度 ×2，求面积 ×4，求角度不变。
  - 同时做 k=1 的"擦掉再重画同一数字"，作为编辑伪影对照。
  - 构造流程：OCR 定位 → 重绘 → 再次 OCR 验证，失败的题直接丢弃。我会随机抽 30 张逐张看图核对并留记录（这不是人工金标）。
- **次要**：MathVista testmini（完整 1000 题、几何 GPS 子集、去掉 Geometry3K 来源后的 938 题）。用我们自己的确定性答案抽取，不等同于官方榜单协议。
- **训练动态**：每步记录答案准确率、断言条数、UNKNOWN 占比、FALSE 率、生成长度、熵。

### 2.5 预注册的主终点与统计

训练开始前，本节会写成 `docs/experiments/预注册_<日期>.md` 并提交，用 git 时间戳作为证据。

- **E1 感知**：val 上的 v5 验证精度和认证召回。比较 RL-v5 vs RL-ans，以及 RL-v5 vs RL-v4（另报断言条数膨胀）。
- **E2 读图**：CF-Geo 放大题上的准确率。比较 RL-v5 vs RL-ans、RL-v5-placebo、RL-blind；k=1 题作为伪影对照。
- **E3 解题**：test 视觉必需子集准确率。比较 RL-v5 vs RL-ans，以及 RL-ans vs RL-blind。
- **统计方法**：
  - 逐题配对；多种子的组先在每道题上取平均。
  - 按图像像素哈希做聚类 bootstrap（1 万次），给出 95% 区间。
  - McNemar 精确检验；主比较做 Holm 校正。
  - "能和对照区分"定义为 95% 区间不跨 0。

### 2.6 预期结果与判读规则（提前写明，避免事后挑结果）

- **大概率能区分**：
  - E1：RL-ans 没有感知奖励，它的感知精度和召回应明显低于 RL-v5。
  - 有图训练的组 vs RL-blind：在视觉必需子集和 CF-Geo 上的差距。
- **不确定**：RL-v5 vs RL-ans 的答案准确率。
- **判读规则**：
  - RL-v5 感知变好但答案不变：结论写成"感知改善未转化为解题"，不夸大。
  - RL-blind 接近 RL-ans：答案增益主要来自语言侧，主结论落在 E1 和 E2。
  - V0 在 CF-Geo 上已经很高：说明"盲猜"前提在这个基座上不成立，改为讲"误读"。

| 决策 | 理由 |
