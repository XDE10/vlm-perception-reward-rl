# Shuffle-R1 第 150 步结果

2026-11-23。Qwen2.5-VL-3B-Instruct 在清洗后的 27,436 条训练样本上完成 150 步。下列为同一第 150 步 checkpoint 的公开测评，温度 0.5，最多 2,048 个新 token，种子 0–7。全量共 13,171 个输入、105,368 条作答。

## 六套公开评测

每项依次列出本项目结果、论文 3B Base 和论文 Shuffle-R1 3B。论文参照值来自表 9 的 3B Base 及表 3 的 3B 联合训练项。提取及判分与论文使用的 Gemini 2.0 Flash 001 存在差异，这些数值为协议近似的对照。[Shuffle-R1 论文](https://arxiv.org/html/2508.05612v6)

- **MathVerse**（3,940 题）为 **42.61%**、34.77%、44.20%。原判 **40.75%**。离线在原作答上修复嵌套公式抽取、明确数学等价与单位漏判，补回 587 条。另计参考答案一处体积单位勘误为 **42.72%**。
- **MathVision**（3,040 题）为 **24.83%**、21.94%、26.80%。原判 **24.63%**，主分经离线等价复核。
- **MathVista**（1,000 题）为 **69.20%**、58.40%、70.40%。
- **WeMath Loose**（1,740 个题输入）为 **58.58%**、51.72%、66.50%。
- **HallusionBench**（951 题）为 **67.98%**、59.83%、69.20%。
- **ChartQA**（2,500 题）为 **77.59%**、73.08%、79.90%。

WeMath 成果展示采用**逐题准确率 63.51%（8,841/13,920）**。子题正确率 66.97%，综合题正确率 55.52%。525 道综合题中 139 道八次全错。与论文比较时采用 Loose。论文附录 F 标明 Loose，公开实现直接算逐题准确率，论文实际运行口径待核实。

## 内部验证与历史对照

- **内部 dev**。按图像家族划出的固定 256 题上，第 150 步答案正确率为 **59.0%**，比第 144 步低约 **4.7 个百分点**。
- **历史 WeMath 单次对照**。同题、同图、同提示下，第 144 步为 **55.71–55.90% Loose**，第 150 步为 **58.86% Loose**。这一对照只覆盖 WeMath 单次推理。

原作答、原判与离线复核逐条证据由项目维护者归档。公开实现的[生成入口](../shuffle_r1/README.md)可用于检验输入或生成新的作答。协议 v3 的 S4/S5 状态见 [训练与终评](training.md)。
